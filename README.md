# 夢幻物語（開発中）

2D縦スクロール弾幕STG。ブラウザで動く（HTML5 Canvas + JavaScript、インストール不要）。

## 遊び方
`index.html` をダブルクリックしてブラウザ（Chrome / Edge）で開く。

| 操作 | キー |
|---|---|
| 移動 | 矢印キー |
| 低速移動（当たり判定表示） | Shift |
| ショット / 決定 / 会話送り | Z |
| 獏喰（ボム） / 戻る | X |
| ポーズ | Esc |
| ミュート | M |
| 会話スキップ | Ctrl |
| 無敵モード ON / OFF（確認用・ステージ中だけ。タイトルに戻ると解除） | Ctrl をすばやく3回 |

## 現在の内容
- 第一夢「予知夢」：道中 → 中ボス → ボス（通常2 + 夢札4）
- 第二夢「悪夢」：道中 → 中ボス → ボス（通常2 + 夢札4）。闇が迫り、夢かじりで押し返す
- 第三夢「吉夢」：道中 → 中ボス（夢魔） → ボス（通常2 + 夢札4）。金の福は当たらないが、取るとまどろんで遅くなる
- 第四夢「逆夢」：道中 → 中ボス → ボス（通常2 + 夢札4）。砂時計が返ると白抜きの弾が逆走、「凶」の印が安全地帯
- 第五夢「残夢」：道中 → 中ボス → ボス（通常2 + 夢札5）。薄れた弾が戻り、巻き戻る。ボスは第一〜第四夢を「回想」する
- 最終夢「夢そのもの」：道中（五つの夢の走馬灯）→ 中ボス（獏の影） → ラスボス 夢の精霊（通常3 + 夢札6、最後は耐久） → エンディング
- 「はじめる」は第一夢から最後まで。「練習（夢を選ぶ）」は好きな面を一つだけ遊ぶ
- 残機アップ：2000万点 → 4000万点 → 8000万点 …（倍々）で残機+1。第二・三・四・最終夢の中ボスを倒すと残機アイテム「命」を落とす
- アイテム回収ライン：画面上部の線（Item Get Border Line）より上で、Pと点を全部吸い寄せる
- ハイスコアは、練習でなく無敵モードも使わずに遊んだときだけ保存される
- 難易度：浅い眠り / 眠り / 深い眠り / 醒めない夢
- システム：夢かじり（グレイズ）、満腹ゲージ、獏喰（ボム）、喰らいボム、食べ残し、夢札取得履歴、ハイスコア保存

# 夢幻物語（開発中）

2D縦スクロール弾幕STG。ブラウザで動く（HTML5 Canvas + JavaScript、インストール不要）。

## 遊び方
`index.html` をダブルクリックしてブラウザ（Chrome / Edge）で開く。

| 操作 | キー |
|---|---|
| 移動 | 矢印キー |
| 低速移動（当たり判定表示） | Shift |
| ショット / 決定 / 会話送り | Z |
| 獏喰（ボム） / 戻る | X |
| ポーズ | Esc |
| ミュート | M |
| 会話スキップ | Ctrl |

## 現在の内容
- 第一夢「予知夢」：道中 → 中ボス → ボス（通常2 + 夢札4）
- 第二夢「悪夢」：道中 → 中ボス → ボス（通常2 + 夢札4）。闇が迫り、夢かじりで押し返す
- 練習モード：タイトルの「練習（夢を選ぶ）」から好きな面を遊べる（ハイスコアは保存されない）
- 難易度：浅い眠り / 眠り / 深い眠り / 醒めない夢
- システム：夢かじり（グレイズ）、満腹ゲージ、獏喰（ボム）、喰らいボム、食べ残し、夢札取得履歴、ハイスコア保存

## ファイル構成
| ファイル | 中身 |
|---|---|
| `js/util.js` | 定数・難易度・入力・タスク（`yield n` で n フレーム待つ仕組み） |
| `js/audio.js` | 効果音（合成） |
| `js/art.js` | **キャラ絵の差し替え口** |
| `js/sprites.js` | 弾・アイテムの見た目 |
| `js/effects.js` | 演出・予告線 |
| `js/bullet.js` / `items.js` / `player.js` / `enemy.js` | 弾・アイテム・自機・敵とボス |
| `js/stage1.js` | **第一夢の背景・雑魚・弾幕・道中・ボス・セリフ** |
| `js/stage2.js` | **第二夢の背景・雑魚・弾幕・道中・ボス・セリフ** |
| `js/game.js` | シーン管理・当たり判定・UI |
